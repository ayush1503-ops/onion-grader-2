# Chapter 8 — Cropping an Image
> 🎥 **PLAYLIST CONTENT** — Part 7 "Cropping an Image".

## 1. Learning Objectives
1. Crop with NumPy slicing. 2. Understand `img[y1:y2, x1:x2]`. 3. Isolate a region of interest (ROI).

## 2. Simple Explanation
Cropping means "keep only this rectangle". Because an image is a NumPy array, you crop it exactly like you slice a list — no special function needed.

## 3. Technical Explanation
```python
roi = img[y1:y2, x1:x2]    # rows y1..y2-1, columns x1..x2-1
```
Remember: **first index = rows = y (top→bottom), second = columns = x (left→right)**.

## 4. Real-World Example
Cutting a face out of a group photo; zooming into a product in a catalog.

## 5. OpenCV Example
```python
import cv2
img = cv2.imread("images/demo_good.jpg")
h, w = img.shape[:2]
center = img[h//4:3*h//4, w//4:3*w//4]   # middle 50%
cv2.imshow("Center crop", center); cv2.waitKey(0)
```

## 6. 🧅 Onion Project Example
The onion rarely fills the whole photo. We crop around it (using a bounding box from Chapter 18) to remove background clutter before analysis.

## 7. Practical Code + 8. Expected Output
```python
roi = img[100:500, 100:500]
print(roi.shape)          # (400, 400, 3)
```

## 9. Visual Explanation
```text
full image               slice img[100:500, 100:500]
┌──────────────┐          ┌──────────┐
│              │          │  ROI     │
│   ┌──────┐   │   -->    │          │
│   │ ROI  │   │          └──────────┘
│   └──────┘   │
└──────────────┘
```
**See → Do → Why → Result:** pick row/col ranges → slice → fewer background pixels → analysis focuses on the onion.

## 10. Common Mistakes
- Mixing x and y order (`img[x1:x2, y1:y2]` is wrong).
- Forgetting that the end index is exclusive (`y2` is not included).
- Cropping outside the image → empty array.

## 11. Practice Task
Crop the top-left quarter and the center quarter; display both.

## 12. Questions + Solutions
- **Q:** Why does cropping use `[]` not a function? **A:** images are NumPy arrays; slicing is array syntax.
- **Q:** In `img[y1:y2, x1:x2]`, what's the first pair? **A:** rows (vertical).

# Chapter 9 — Saving an Image
> 🎥 **PLAYLIST CONTENT** — Part 8 "Saving an Image".

## 1. Learning Objectives
1. Save with `cv2.imwrite`. 2. Control format/quality. 3. Save pipeline outputs.

## 2. Simple Explanation
`cv2.imwrite("path.jpg", img)` writes the array to disk as an image file. The extension you choose decides the format (`.jpg`, `.png`, …).

## 3. Technical Explanation
```python
ok = cv2.imwrite("out.png", img)     # returns True on success
cv2.imwrite("out.jpg", img, [cv2.IMWRITE_JPEG_QUALITY, 90])   # quality 0-100
```
- `.jpg` — lossy, small, no transparency.
- `.png` — lossless, larger, supports transparency.

## 4. Real-World Example
Saving a photo after applying a filter; exporting model outputs.

## 5. OpenCV Example
```python
import cv2
img = cv2.imread("images/demo_good.jpg")
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
cv2.imwrite("images/gray.png", gray)
```

## 6. 🧅 Onion Project Example
Every pipeline stage we run saves its output (`01_original.jpg` … `09_result.jpg`). Saving intermediate steps is how you **debug** — you can look at exactly where the pipeline went wrong.

## 7. Practical Code + 8. Expected Output
```python

```

# Chapter 10 — Drawing Shapes & Text
> 🎥 **PLAYLIST CONTENT** — Part 9 "Drawing Shapes and Text on Images".

## 1. Learning Objectives
1. Draw lines, rectangles, circles with `cv2.line/rectangle/circle`. 2. Write text with `cv2.putText`. 3. Annotate images for display.

## 2. Simple Explanation
Drawing lets you **write on** an image: outline a region, box an object, or label it. This is how the analyzer will show its answer right on the photo.

## 3. Technical Explanation
```python
cv2.line(img, (x1,y1), (x2,y2), color, thickness)
cv2.rectangle(img, (x1,y1), (x2,y2), color, thickness)   # or thickness=-1 to fill
cv2.circle(img, (cx,cy), radius, color, thickness)
cv2.putText(img, text, (x,y), fontFace, fontScale, color, thickness, lineType)
```
Colors are BGR tuples. Coordinates are (x, y).

## 4. Real-World Example
Face-detection boxes, self-driving car bounding boxes, sports overlays.

## 5. OpenCV Example
```python
import cv2
img = cv2.imread("images/demo_good.jpg")

cv2.circle(img, (320, 320), 80, (0, 0, 255), 3)                    # red circle
cv2.putText(img, "ONION", (50, 40), cv2.FONT_HERSHEY_SIMPLEX, 1.2, (0, 200, 0), 3)
cv2.imshow("Annotated", img); cv2.waitKey(0)
```

# Chapter 11 — Mouse Events (Part 1 & 2)
> 🎥 **PLAYLIST CONTENT** — Parts 10 & 11 "Working with OpenCV Events".

## 1. Learning Objectives
1. Register a mouse callback with `cv2.setMouseCallback`. 2. Read click coordinates. 3. Build interactive tools.

## 2. Simple Explanation
A **callback** is a function you write that OpenCV calls automatically whenever something happens (mouse click, move). You register it once, then OpenCV "calls you back" on each event.

## 3. Technical Explanation
```python
def on_mouse(event, x, y, flags, param):
    if event == cv2.EVENT_LBUTTONDOWN:
        print("clicked at", x, y)

cv2.setMouseCallback("window", on_mouse)
```
Events include `EVENT_LBUTTONDOWN`, `EVENT_RBUTTONDOWN`, `EVENT_MOUSEMOVE`, etc.

## 4. Real-World Example
Every drawing app (paint, annotation tools, image editors) is built on exactly this mechanism.

## 5. OpenCV Example
```python
import cv2
img = cv2.imread("images/demo_good.jpg")
def click(event, x, y, flags, param):
    if event == cv2.EVENT_LBUTTONDOWN:
        cv2.circle(img, (x, y), 6, (0, 0, 255), -1)
        cv2.imshow("window", img)
cv2.imshow("window", img)
cv2.setMouseCallback("window", click)
cv2.waitKey(0)
```

## 6. 🧅 Onion Project Example
You'll build a **labeling tool** (Chapter 21) where you click on defect areas to mark them — mouse events are how you create labeled data fast.

# Chapter 12 — Mini-Project: The Cropping Tool
> 🎥 **PLAYLIST CONTENT** — Part 12 "Building a Cropping Tool".

## 1. Learning Objectives
1. Combine events + drawing + slicing into a real app. 2. Select a region by dragging. 3. Save the cropped ROI.

## 2. Simple Explanation
You now have every piece: mouse events (click/drag), drawing (show the selection rectangle), and slicing (crop). This chapter glues them into a **cropping tool** — your first real, useful program.

## 3. Technical Explanation
Plan: on left-button-down record the start point; on mouse-move update the rectangle; on button-up record the end point, crop `img[y1:y2, x1:x2]`, save it.

## 4. Real-World Example
The crop tool in every photo app and the "select ROI" box in labeling software.

## 5. OpenCV Example
```python
import cv2
img = cv2.imread("images/demo_good.jpg")
clone = img.copy()
start, drawing = None, False

def on_mouse(event, x, y, flags, param):
    global start, drawing
    if event == cv2.EVENT_LBUTTONDOWN:
        start, drawing = (x, y), True
    elif event == cv2.EVENT_MOUSEMOVE and drawing:
        tmp = clone.copy()
        cv2.rectangle(tmp, start, (x, y), (0, 255, 0), 2)
        cv2.imshow("crop", tmp)
    elif event == cv2.EVENT_LBUTTONUP:
        drawing = False
        x1, y1 = start
        roi = clone[min(y1,y):max(y1,y), min(x1,x):max(x1,x)]
        cv2.imwrite("images/crop.jpg", roi)
        print("saved crop:", roi.shape)

cv2.imshow("crop", clone)
cv2.setMouseCallback("crop", on_mouse)
cv2.waitKey(0)
```

## 6. 🧅 Onion Project Example
Use this tool to crop the onion out of your photos so the dataset contains mostly onion, not background.

## 7. Practical Code — see above. 8. Expected Output

# Chapter 13 — Working with Video
> 🎥 **PLAYLIST CONTENT** — Part 13 "Working with Videos using OpenCV".

## 1. Learning Objectives
1. Open video with `cv2.VideoCapture`. 2. Loop over frames. 3. Write video with `VideoWriter`. 4. Use a webcam.

## 2. Simple Explanation
Video is just a fast slideshow of images (**frames**). Processing video = loop over frames, apply the same image operations to each one.

## 3. Technical Explanation
```python
cap = cv2.VideoCapture("clip.mp4")     # or 0 for webcam
while True:
    ok, frame = cap.read()             # ok=False at the end
    if not ok: break
    # ... process frame ...
cap.release()
```
To write: `cv2.VideoWriter("out.avi", cv2.VideoWriter_fourcc(*"MJPG"), fps, (w, h))`.

## 4. Real-World Example
Security cameras, YouTube uploads, and every live video app.

## 5. OpenCV Example
```python
import cv2
cap = cv2.VideoCapture("videos/part02.h264.mp4")
n = 0
while True:
    ok, frame = cap.read()
    if not ok: break
    n += 1
    if n % 30 == 0:                    # process every 30th frame
        cv2.imshow("frame", frame)
        if cv2.waitKey(1) & 0xFF == ord("q"): break
cap.release(); cv2.destroyAllWindows()
print("total frames:", n)
```

## 6. 🧅 Onion Project Example
Point a webcam at onions on a conveyor (or your desk) and run the analyzer on each frame — a **live** quality checker.
