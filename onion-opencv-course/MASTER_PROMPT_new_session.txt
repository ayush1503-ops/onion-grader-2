## PROJECT (Smart India Hackathon 2026 — Problem SIH26031)
"Quality assessment and grading of onions are often subjective and vary across
procurement centers, resulting in disputes and inconsistencies."
Build an AI-based mobile application that:
1. Uses image processing to assess onion quality.
2. Identifies damaged, rotten, sprouted, or undersized onions.
3. Estimates Grade A and URS percentages.
4. Generates a digital quality report instantly.
5. Reduces human bias and improves transparency.

## REQUIRED FEATURES (build all of these)
A. IMAGE INPUT: analyze a photo of a batch of onions.
B. LIVE CAMERA SYSTEM: capture from webcam (laptop) AND from a phone camera
   via a web app. Must have a "Snapshot / Capture" button and a live preview.
C. EXACT ONION COUNT: count every onion correctly. If onions are TOUCHING,
   split them using the WATERSHED algorithm (cv2.watershed) so touching onions
   are not counted as one.
D. CLASSIFICATION per onion: GOOD / DAMAGED / ROTTEN / SPROUTED / UNDERSIZED.
E. SIZE MEASUREMENT: measure each onion's diameter in MILLIMETERS using a
   reference object in the photo (an Indian coin: Rs.10/Rs.2 = 27 mm, Rs.5 = 23 mm,
   Rs.1 = 22 mm). Also allow the user to type the reference size in mm.
F. GRADING: Grade A = 45–65 mm, Grade URS = 35–70 mm (relaxed spec), else REJECT.
   Compute the percentages: % Grade A, % URS, % Reject.
G. DIGITAL REPORT: instantly produce (1) an annotated image with each onion
   labeled + boxed + sized, (2) a JSON report, (3) a text report, (4) a
   report-card image. Include date/time and batch ID.

## ADVANCED AI SYSTEM (I want it to look modern and smart)
Include TWO modes and let me switch between them:
- MODE 1 — Classic CV (fast, no training): OpenCV pipeline
  (grayscale → Gaussian blur → Otsu threshold → morphology → contours →
   watershed → HSV color features → rules).
- MODE 2 — Deep Learning AI: use YOLOv8 (ultralytics library) to DETECT each
  onion in one shot, then classify each crop with a small CNN (or YOLO classes).
  Use a free pre-trained YOLOv8n model and show me how to FINE-TUNE it later on
  my own labeled dataset. YOLO must handle detection; the size/grade logic
  stays the same on top of the detections.
